The documents that govern what gets built. Where these and the code disagree,
these are right and the code is behind.

Product and curriculum planning — activity outlines, subject content, teaching
material — lives separately in `Documents\The Brain Bureau` on Maciej's
machine. Roughly: **that folder is what the activities teach; this one is what
the platform does.**

## Conventions

Each document marks its own status. **Decided** items are settled and may be
built against. **Proposed** items are my recommendation awaiting a yes.
**OPEN** items genuinely need a decision and are collected at the end of
[roadmap.md](roadmap.md).

Divergences between spec and code are recorded rather than quietly fixed, so
the gap is visible — see the table at the end of
[product-overview.md](product-overview.md).
